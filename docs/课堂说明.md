## 上课方式（重要）

- **必须用系统浏览器（Edge/Chrome）打开课堂**，不要用豆包等内置浏览器：内置浏览器（webview）没有麦克风权限授权通道，语音输入必然失败（`not-allowed`）
- 首次使用麦克风会弹权限请求，点「允许」；误点「阻止」则到地址栏左侧站点设置改为允许
- AI 教师语音讲解、白板演示、测验判分、随时提问均可使用

## 换老师声音

生成新课堂时指定音色（7 种中文音色）：

```bash
python skill/scripts/generate_classroom.py --requirement "..." --voice "温润男声"
# 可选：电台男主播 / 温暖少女 / 新闻女声 / 少女音色 / 精英青年 / 御姐音色
```

注意：**已生成课堂的音频不会随设置变化**，换音色必须重新生成课堂。

## 常见问题

| 现象 | 处理 |
|---|---|
| 服务未启动 | 见部署指南：PostgreSQL 服务 Running + `C:\OpenMAIC` 下 `pnpm dev` |
| 生成某场景反复失败 | `openmaic.yml` 的 `llm`/`course.content` 指向 `MiniMax-M3`（M2.7 会失败），改后重启并用 `--resume` 续跑 |
| 新浏览器看不到课堂 | 检查 `.env.local` 是否 `OWNER_SINGLE_USER=true` |
